# Revitalize with Mahira | Clinical Nutrition & Weight Management

Official brand website for **Coach Mahira** ([@mahira_244](https://www.instagram.com/mahira_244/?hl=en) / *Revitalize with Maira*), built with Vue 3, Vite, and Tailwind CSS.

## 🌿 Core Features
- **Live Instagram & Video Reels**: Real-time synced profile feed and interactive vertical 9:16 reels player with like counter, recipes, and direct WhatsApp DM "FIT" triggers.
- **Interactive Macro & Calorie Calculator**: Scientific BMR/TDEE assessment tool computing daily protein, carbs, and fats.
- **Tailored Nutrition Protocols**: 30-Day Reset, 90-Day Metabolic Transformation, PCOS Care, and Healthy Weight Gain.
- **Verified Client Transformations**: Measurable metrics (-7.8kg, +5.4kg muscle, cycle normalization) and review quotes.
- **Signature High-Protein Recipes**: Featuring Coach Mahira's viral *High-Protein Chicken & Chickpea Macaroni Salad* (420 kcal, 38g protein).
- **Working Hours & Availability**: Real-time clinic status indicator with international timezone support.
- **4-Step Interactive Appointment Booking**: Multi-step calendar, time slots, intake questionnaire, and instant WhatsApp confirmation.

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```

## 📦 Deployment
Configured for automated zero-config deployment on Vercel (`vercel.json` included).
